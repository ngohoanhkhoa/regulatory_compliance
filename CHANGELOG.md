# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Unified **dataset registry** for private documents and shared regulatory
  collections, with a single Datasets management UI.
- Regulatory **dataset import/export** bundles (`.rcdataset.zip`, optional
  precomputed embeddings) for distributing processed text collections.
- **Multi-dataset chat** with a dataset selector, and an `@`-mention picker to
  scope a question to specific documents or acts.
- Per-user **document library** (PDF/DOCX/TXT/MD/CSV upload, tags, semantic
  search).
- **Topics** with saved search filters and timeline refresh.
- **Admin user management** (create, rename, reset password, grant/revoke
  admin, hard-delete) and self-service username/password changes.
- Grounding guardrail, citation formatter, and an evaluation script.
